# Le St-Mos

Site bilingue (FR | EN) du café Le St-Mos — comptoir à thés & fouettés.

## Développement / Development

Site statique, sans étape de build. Pour le voir localement :

```sh
python3 -m http.server 8000
# http://localhost:8000  (ou ?lang=en)
```

Déployable tel quel sur Vercel (ou tout hébergeur statique).
